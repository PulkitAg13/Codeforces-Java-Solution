## 🛠️ How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/PulkitAg13/Codeforces-Java-Solutions.git
   ```
2. Navigate to any solution:

   ```bash
   cd Codeforces-Java-Solutions/solutions
   ```
3. Compile and run:

   ```bash
   javac ProblemA.java
   java ProblemA
   ```
